## 第一章 产品概述

### 1.1 产品背景

《鸡架老板模拟器》是一款以餐饮创业为主题的模拟经营游戏。玩家扮演一位从互联网大厂供应链计划岗位离职的打工人，因热爱拌鸡架而决定开一家鸡架加盟店，最终通过经营、研发、竞争，脱离品牌控制，建立自己的品牌并收购原品牌总部。

游戏融合了资源管理、人员管理、配方研发、多渠道运营、风险应对等玩法，以周为单位推进时间，时间跨度约2年（104周）。

### 1.2 产品定位

| 项目 | 内容 |
|------|------|
| 目标平台 | 网页游戏 / 微信小程序 |
| 目标玩家 | 休闲玩家与模拟经营爱好者兼顾 |
| 视觉风格 | 卡通像素风，轻松幽默 |
| 社交功能 | 纯单机体验，无多人功能 |
| 时间推进 | 回合制，玩家手动推进下一周 |
| 存档机制 | 多存档槽位（3-5个），允许回溯决策 |
| 数值平衡 | 偏硬核真实，前期宽松后期有挑战 |
| 剧情演出 | 精简剧情+系统提示，关键节点有剧情 |

### 1.3 核心体验目标

- **经营真实感**：数值偏硬核，资金压力、库存管理、人员问题等挑战真实
- **成长成就感**：从加盟店到独立品牌，从单店到收购总部，逆袭体验完整
- **策略深度**：配方研发、渠道选择、营销时机、B端合作等决策有策略空间
- **轻松氛围**：像素画风、幽默文案、适度随机事件，避免过度沉重

### 1.4 游戏时长

- 完整通关（达成收购总部结局）：约8-12小时
- 单周游戏时长：约3-8分钟（视决策复杂度）
- 重玩价值：不同配方研发路线、B端合作选择、营销策略等可带来不同体验

## 第二章 核心玩法循环

### 2.1 主循环

游戏以"周"为最小时间单位，每周玩家依次进行以下决策：

| 阶段 | 操作 | 说明 |
|------|------|------|
| 1 | 回顾上周 | 查看销售数据、评价、事件结果、店员状态等 |
| 2 | 采购决策 | 采购下周所需原料（鸡架、配菜、酱料、饮品、打包盒） |
| 3 | 人员管理 | 处理店员情绪、招聘/解雇、分配岗位 |
| 4 | 营销决策 | 参与平台活动、投流、私域运营、B端交付 |
| 5 | 研发投入 | 投入资金研发新配方（可选） |
| 6 | 装修投入 | 购买家具提升线下吸引力（可选） |
| 7 | 推进下周 | 确认决策，系统结算并进入下一周 |

### 2.2 经济循环

**收入来源**：
- 线上外卖平台销售（JD、MT、SG）
- 线下到店消费
- 私域运营销售（WX/XHS引流）
- B端固定供货（足浴店、桌游吧、便利店等）

**支出项目**：
- 一次性支出：加盟费、啤酒销售许可证、装修/家具
- 周常支出：原料采购、店员工资、租金、水电费
- 营销支出：平台活动补贴、投流费用
- 研发支出：配方研发成本（每次10000元）
- 招募支出：每次招募花费2000元

### 2.3 风险与挑战

| 风险类型 | 触发条件 | 后果 |
|---------|---------|------|
| 原料过期 | 未在保质期内使用完 | 继续使用80%概率拉肚子，赔偿×3，5%起诉赔5000 |
| 飞行检查 | 6月、11月随机一周抽查 | 非官方渠道进货有概率不合格，罚款或警告 |
| 店员离职 | 情绪值过低或随机事件 | 需紧急招聘，影响运营效率 |
| 配送差评 | 骑手迟到导致配送速度差评 | 平台评分下降，影响曝光 |
| B端违约 | 未按期交付B端订单 | 赔偿违约金，关系下降，三次终止合作 |
| 品牌竞争 | 第2年6月第1周直营店开业 | 线上线下单量下降，需决策是否脱离品牌 |
| 订单取消 | 原料/人力不足 | 各渠道订单取消，累计取消过多被要求整改 |

## 第三章 用户体力系统

### 3.1 基础规则

| 属性 | 数值 |
|------|------|
| 初始体力 | 每周10点 |
| 恢复方式 | 每周一自动恢复至10点 |
| 体力耗尽 | 体力降为0后强制进入休息状态，跳过本周剩余操作 |

### 3.2 活动体力消耗

| 活动 | 消耗 | 备注 |
|------|------|------|
| 招聘店员 | -1 | 每次招募另花费2000元，当周招募下周到岗 |
| 采购原料 | -1 | 每周必做 |
| 研发配方 | -2 | 每次研发资金10000元 |
| 外卖平台运营 | -1 | 所有平台合计扣1点 |
| 私域运营 | -1 | 所有私域合计扣1点 |
| 拓展B端客户 | -2 | 拜访新客户 |
| 购买店内装潢 | -1 | 每次购买 |
| 获得啤酒许可证 | -1 | 一次性 |
| 下周营销活动策划 | -1 | 提前规划 |
| 与总部运营沟通 | -1 | 建议上架/下架SKU |
| 申诉上周差评订单 | -1 | 处理差评 |

### 3.3 委托机制

**外卖平台运营可委托总部代托管**：
- 不扣除体力
- 收益有20%概率下降10-30%
- 营销费用有15%概率上升10-20%

**私域运营可委托店员代运营**：
- 话术≥9分：获得额外收益+15-25%
- 话术≤7分：有25%概率获得负向结果（差评、退群等）
- 话术8分：正常运营，无额外效果

|------|------|------|------|

| 投影仪 | 8000元 | 否 | 赛事期间客流大加成 |
| 临街广告屏 | 2000元 | 否 | 线下吸引力加成 |

### 4.3 后厨装潢

| 设备 | 价格 | 必须 | 备注 |
|------|------|------|------|

| 空调 | 5000元 | 否 | 6-8月每周5%概率坏，维修300元 |

### 4.4 温控覆盖规则

- 风扇覆盖范围：10平方米
- 空调覆盖范围：60平方米
- 若店铺面积 > 风扇数量×10 + 空调数量×60，则影响**线下顾客满意度**（夏季影响更大），导致差评率上升、复购率下降
- **店面与后厨是否有风扇和空调也影响员工情绪**：温控不足时，员工情绪值每周额外-3~-5点（视缺口程度）

### 4.5 店铺扩张

**一层扩张**：

| 扩张参数 | 数值 |
|---------|------|
| 每次扩张面积 | +20平方米 |
| 扩张费用 | 5000元/次 |
| 租金上涨 | +2500元/月 |
| 店员容量 | +3人 |
| 顾客容量 | +3人 |
| 一层最大面积 | 100平方米 |

**二层修建**：
- 当一层达到100平方米时，继续扩张为修建二层
- 费用：25000元
- 租金上涨：+12500元/月
- 店员容量：+15人
- 顾客容量：+15人
- **二层所有家具装潢都需重新购买（除外卖打包台，打包台共用一层的）**

### 5.2 采购渠道对比

| 渠道 | 价格 | 质量保证 | 飞行检查风险 |
|------|------|---------|-------------|
| 品牌官方 | 较贵（+20-30%） | 100%合格 | 无风险 |
| 批发市场 | 便宜（-15-25%） | 90%合格 | 抽查时30%概率不合格 |

### 5.3 库存管理规则

- 玩家需在当周采购下周所需原料
- 原料按周消耗，超期自动标记为"过期"
- 过期原料可选择：1）扔掉（损失成本）2）继续使用（80%概率触发顾客拉肚子）
- 夏季（6-8月）保质期缩短，需更频繁采购

**保质期规则**：

| 原料分类 | 常温保质期 | 夏季（6-8月）保质期 |
|---------|-----------|------------------|
| 生鸡架 | 2周 | 1周 |
| 官方拌料 | 12周 | 6周 |
| 海带结、贡菜 | 2周 | 1周 |
| 花生米、方便面 | 8周 | 4周 |
| 可乐、冰水、果汁、啤酒 | 30周 | 30周 |

> 注：保质期以"周"为单位，夏季仅影响官方拌料、海带结贡菜类、花生米、方便面（缩短一半），饮品类不受季节影响。

### 5.4 采购界面设计

点击左侧菜单"采购原料"后，界面分为上下两部分：

**上半部分——当前库存一览**：

按原料分组展示总量，默认折叠，展开可查看by到期时间明细。

**一键生成采购单**：点击"预测本周需求"卡片右上角的"一键生成采购单"按钮，系统自动根据预测需求与当前库存的缺口，生成采购清单。默认使用官方渠道，无官方渠道的原料默认批发渠道。用户可手动切换渠道、调整数量后确认采购。

**下半部分——采购下单区**：

- 勾选多个原料 + 输入各原料采购数量
- 系统自动计算总金额（含批量折扣）
- 确认后扣除资金，原料下周初到库

### 5.5 原料分配优先级

当原料不足时，按以下渠道优先级分配，优先级低的渠道订单自动取消：

**B端 > MT > SG > JD > 线下到店 > 私域**

## 第六章 人员系统

### 6.1 店员姓名

从以下三部作品中随机抽取角色名：

| 作品 | 可选角色示例 |
|------|-------------|
| 武林外传 | 佟湘玉、白展堂、郭芙蓉、吕秀才、李大嘴、祝无双、莫小贝、邢捕头、燕小六 |
| 甄嬛传 | 甄嬛、沈眉庄、安陵容、华妃、皇后、端妃、敬妃、齐妃、曹贵人、苏培盛、流朱、浣碧 |
| 三国演义 | 刘备、关羽、张飞、赵云、诸葛亮、曹操、孙权、周瑜、吕布、貂蝉、典韦、许褚 |

### 6.2 技能体系

每个店员拥有5项技能，每项满分10分：

| 技能 | 主要作用 | 具体效果 |
|------|---------|---------|
| 话术 | 沟通、销售、私域运营 | 收银推荐成功率+（话术×2%）；私域运营收益加成 |
| 耐心 | 服务、应对投诉 | 顾客等待容忍度+（耐心×10）秒；差评转化率降低 |
| 体力 | 高强度工作、后厨 | 连续工作时长+（体力×30）分钟；疲劳度上升减缓 |
| 仔细 | 收银、打包、库存 | 出错率降低（仔细×0.5%）；库存盘点准确率提升 |
| 手速 | 后厨、打包 | 制作速度+（手速×5%）；打包速度提升 |

### 6.3 岗位与技能匹配

| 岗位 | 核心技能 | 次要技能 | 技能不足后果 |
|------|---------|---------|-------------|
| 收银 | 话术、仔细 | 手速 | 算错账、推荐失败 |
| 服务员 | 耐心、体力 | 话术 | 顾客投诉、服务慢 |
| 后厨 | 手速、仔细 | 体力 | 出餐慢、配错料 |

### 6.4 招募机制

- 每次招募花费**2000元**，消耗体力1点
- 系统随机生成3-5名候选人
- 每位候选人随机展示2个技能值，其余3个隐藏
- 候选人展示期望工资（3500-4500元随机）
- 玩家可选择：接受原价 或 砍价（默认砍20%）
- 砍价后店员有40%概率拒绝，60%概率接受
- 确定雇佣后，店员下周到岗，所有属性公开

**辞退员工**：在员工沟通界面点击"辞退"，需立即支付员工一个月工资作为遣散费，员工立刻离岗。

### 6.5 身兼多职

- 任意岗位可身兼多职
- 一人兼任两职：工资+30%，工作效率-15%
- 兼任时有20%概率触发顾客不满（等待时间过长、服务态度差评）
- 建议：客流高峰期避免兼任

### 6.6 情绪系统

- 情绪值0-100
- 影响因素：工作强度、工资满意度、随机事件、正向事件、**温控环境**（店面/后厨无风扇空调时每周额外-3~-5点）
- 低于30有概率离职

## 第七章 配方研发系统

### 7.1 官方配方

- 加盟后获得品牌官方拌料配方，配方为黑盒，玩家无法查看具体配比
- 只能使用官方配方制作，可在所有渠道销售
- 脱离品牌后无法继续使用官方配方

### 7.2 自研配方

每次研发资金10000元，消耗体力2点。7种酱料，每种0-3勺：

| 酱料 | 风味类型 | 用量档位 | 风味强度 |
|------|---------|---------|---------|
| 酱油 | 咸鲜基础 | 不放/1勺/2勺/3勺 | 轻度/适中/浓郁 |
| 辣椒油 | 辣味 | 不放/1勺/2勺/3勺 | 微辣/中辣/特辣 |
| 醋 | 酸味 | 不放/1勺/2勺/3勺 | 微酸/酸爽/重酸 |

### 7.3 评分算法

| 评分维度 | 权重 | 计算方式 |
|---------|------|---------|
| 风味平衡 | 30% | 酱料种类适中(3-5种)得分高 |
| 用量协调 | 25% | 各酱料用量差异不过大 |
| 经典搭配 | 25% | 符合经典口味组合加分 |
| 创新度 | 10% | 独特组合有额外加分 |
| 随机波动 | 10% | ±1分随机波动 |

### 7.4 美味分数等级

| 分数 | 等级 | 效果 |

| 原料采购 | 2,000-5,000元/周 | 根据销量预估 |
| B端配送费 | 商家数×100元/周 | 三方骑手配送 |

### 19.3 月度结算

**工资、水电在每月第1周扣除（第2个月起）；房租第1-3月免除（人才补贴），第5月第1周起扣除。**
